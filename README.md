# CBU TAAS Diagnostics ReAct AI Agent

- **Name:** Eswar
- **Track:** Agentic AI / AI Engineering
- **Lab Name:** Lab 1 - ReAct Diagnostics Agent

## What It Does
An autonomous diagnostic agent built using the Hugging Face Inference API (`Qwen/Qwen2.5-72B-Instruct`). It uses an explicit ReAct (Reasoning + Acting) loop to analyze automated test failures, query logs, verify endpoint statuses, and inspect database metrics to provide root cause reports.
